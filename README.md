# The_Impact_of_Heterogeneous_Contact_Structure_on_the_Evolution_of_Pathogen_Virulence
Example MATLAB code for results obtain in the article: "The Impact of Heterogeneous Contact Structure on the Evolution of Pathogen Virulence" by O'Neill et al.

Note, all data files have been trimmed to contain only the essential. This essential data contains the last 4000 time points of data, storing only the graph data structure, G, the virulence over time, Alpha_over_time, the infected status of individuals over time, I_over_time, the susceptible status of individuals over time, S_over_time, and the mean virulence over time. All can be used to run the scripts to produce figures. The tightening of these data structures was required so that the size was small enough to be uploaded.
